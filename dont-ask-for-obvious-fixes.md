When a fix is obviously within the current mandate, apply it — don't end the turn asking
"want me to fix X?". Named examples from my human partner: a bug in a doc (e.g. a misattributed claim),
and tone-matching a draft to an already-agreed style. These need no approval round-trip.

**Why:** asking for the obvious wastes a turn and signals low agency; my human partner expects the work
done, then reported.

**How to apply:** if the fix is (a) clearly correct, (b) inside the task already agreed, and
(c) low-risk/reversible, do it and report it. Still ask when the choice is genuinely the
user's (venue, strategy, anything outward-facing like posting). Reserve questions for real
forks. See [[always-write-drafts-to-file]].
