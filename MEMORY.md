- [markdown reflow gate](markdown-reflow-gate.md) — wiring a markdown hard-wrap gate (rumdl 0.2.74): the gate is `rumdl fmt --check -q --no-cache`, never `rumdl check` — permanently red on a line it cannot wrap; `include = ["*.md"]` is not root-anchored, the `*` crosses `/` and pulls in `plans/`, `memory/`, `.claude/` — root-level files are `/*.md`; without `--no-cache` a `.rumdl_cache/` dir appears in the tree; `reflow = true` alone only breaks over-limit lines and never converges widths (a ~70-col doc comes out *longer*) — `reflow-mode = "normalize"` re-fills paragraphs and is what a line-count cap is measured against, formatter check ahead of the line guard (the ddaanet size cap counts bytes and needs no reflow); reflow adds `>` to wrapped blockquote continuations, realigns table separators, and breaks any checker that greps a `- ` bullet line for content
- [rumdl unwrappable span](rumdl-unwrappable-span.md) — `[MD013] Line length N exceeds 80` left by `rumdl fmt` on a long code span or `*`/`**` emphasis run: fmt re-joins a hand split; move the span into a fenced block — punctuation after the closing backtick is lost and a hand-wrapped span's newline becomes a real break
