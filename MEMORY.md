- [Plans carry contracts, not code](plan-contracts-not-full-code.md) — verbatim only for interfaces and boundary-crossing strings; writing-plans demands full bodies and must be overridden

- [Genuine red, not missing SUT](genuine-red-not-missing-sut.md) — TDD red = failed assertion (stub-then-assert), never a missing module; plan interfaces one contract per line
- [Don't bake in guarantees](dont-bake-in-guarantees.md) — a guarantee a later caller must relax belongs in an opt-in method, not hardcoded into every call (fsync → Ledger.sync())

- [No internal back-compat](no-internal-back-compat.md) — don't keep backward compatibility for internal clients; change the callers instead
- [Agent hooks need exact trust key](agent-hooks-need-exact-trust-key.md) — `.claude/agents` frontmatter `hooks:` silently skipped ("Skipping frontmatter hooks", `tengu_agent_hooks_origin_untrusted`) when `~/.claude.json` `hasTrustDialogAccepted` is false for the exact project path; inherited parent trust hides it and no dialog ever appears — necessary but not sufficient, a second silent gate is the dispatch's name, and a provoke-check must read the tool result, not the agent's report
- [Named dispatch drops frontmatter hooks](named-dispatch-drops-frontmatter-hooks.md) — spawning a custom agent with a `name` overwrites the dispatch's `agentType` with that name and demotes the definition to `customAgentType`; frontmatter `hooks:` resolve by `agentType`, so a named dispatch silently registers zero hooks and runs uncontained

- [Verify restart before structural diagnosis](verify-restart-before-structural-diagnosis.md) — a same-session negative result (PATH/new agent not visible) often just needs a harness restart, not a structural cause
- [Parse, don't regex, structured formats](parse-dont-regex-structured-formats.md) — use a real parser for YAML/JSON/TOML/HTML, never a hand-rolled regex even for "just one field"; regex is for genuine token extraction from prose
