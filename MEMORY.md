# ddaanet tier index

Portable facts that hold across every ddaanet project — tooling behaviour,
Claude Code mechanics, shell and git gotchas. Project-specific facts stay in
the project's own memory store.

- [sandbox effects](sandbox-effects.md) — index.lock/"Another git process" (mask vs genuinely-stale: only a real lock survives unsandboxed), phantom dotfiles as char devices or zero-byte files (break `git add -A`; real while ANY agent's sandbox is live, so one clean reading proves nothing), sibling worktree "Read-only file system", "Device or resource busy" on .claude/settings.json & .git/config (blocks git checkout/reset --hard), own hooks.json unlink EROFS, --resume "No conversation found…", $TMPDIR unset, zellij "no active session"; escapes incl. dangerouslyDisableSandbox
- [bats + shellcheck gotchas](bats-shellcheck-gotchas.md) — SC2314 bare `! cmd` asserts nothing; `run missing_fn` exits 127 so negatives pass vacuously; a helper's `${n:-default}` erases the empty-arg case; `grep -qF` matches any ONE line of a multi-line pattern; @test bodies run under errexit; shellcheck lints .bats; `# shellcheck` comment = directive
- [git refuses ext:: by default](git-ext-transport.md) — `fatal: transport 'ext' not allowed`; `protocol.ext.allow` defaults `never`, so an `ext::sh -c` injection finding isn't exploitable on default git — probe the policy first
- [protocol.file.allow blocks submodule clones](git-protocol-file-allow.md) — `fatal: transport 'file' not allowed`; the child *clone* reads it, so repo config can't fix it — `git -c`
- [design-doc writing](design-doc-writing.md) — where dated rationale goes vs present-tense truth; the six sections (FR, NFR, architecture, decisions, rejected alternatives, changelog); `(implemented <date>)` tags are changelog material
- [CC project-dir encoding](cc-project-dir-encoding.md) — `~/.claude/projects/<name>/` = abs path with `[^A-Za-z0-9]`→`-`; to find a transcript search `<session-id>.jsonl`, don't apply the rule; edify's impl is incomplete
- [CC agent discovery](cc-agent-discovery.md) — `Agent type not found`: `<plugin>:<agent>`, never the bare name; marketplace-install vs `--plugin-dir` (cwd `agents/` is not auto-discovered), and per-session definition caching
- [git hook env leak](git-hook-env-leak.md) — `index file open failed: Not a directory` in a hook = leaked repo-local `GIT_*`; `unset $(git rev-parse --local-env-vars)`, but save/restore `GIT_INDEX_FILE` for a staging `git add` or it dies on `Unable to create '.git/index.lock': File exists`
- [submodule escape to parent](submodule-escape-to-parent.md) — `git -C`/`cd` into a submodule with no `.git` silently operates on the **parent**; symptom: bogus 160000 gitlink or a stray `git branch`; linked worktree = `--git-dir` ≠ `--git-common-dir`
- [submodule url arrives rewritten](submodule-url-arrives-rewritten.md) — matching a submodule's `remote.origin.url` against a marker you wrote into `.gitmodules`: git absolutizes a relative url on the way in, so the literal is only ever visible to a `.gitmodules` read; and an entry with no `url` at all cannot be initialized
- [CC sub-agent approval](cc-subagent-approval.md) — `No agent named 'X' is currently addressable`: a one-shot sub-agent has no parent to `SendMessage`; a bare `idle_notification` is not a report
- [CC command namespacing](cc-command-namespacing.md) — `/<plugin>:<path-under-commands>`, so `commands/gitlore/install.md` becomes `/gitlore:gitlore:install`; and a skill colliding on the same `<plugin>:<name>`
- [stale plugin code](stale-plugin-code.md) — running plugin code ≠ what you edited: `/plugin update` no-ops on unchanged version, skill bodies need `/reload-plugins`, `hooks.json` events frozen at session start, `settings.local.json` not
- [plugin recurse-clone submodule](plugin-recurse-clone.md) — `/plugin install` clones `--recurse-submodules`, so a relative submodule url → `not a valid repository name` and install aborts; `--plugin-dir` does not recurse, so dogfooding can't catch it
- [`!` shell shares agent cwd](bang-shell-shared-cwd.md) — the user's `!` shell and the agent's Bash share one cwd, so a stale `cd` relocates the command; symptom: push says `Everything up-to-date` from inside a submodule
- [session title: hook field + custom-title entry](session-title-customtitle.md) — `hookSpecificOutput.sessionTitle` at `SessionStart` (in-memory) and `UserPromptSubmit` (persists) ONLY; storage is a last-wins `custom-title` jsonl entry; `/rename`, `-n`, ctrl+R write the same
- [PostToolUse additionalContext in --print mode](posttooluse-print-mode.md) — `--print` vs SDK `query()` as a scripted harness: which hooks fire (incl. `PostToolBatch`), whether `additionalContext` injects, how each does multi-turn (`--print --resume`), and what to pick on (cost/latency in the file); `claude -p` is NOT read-only — `SessionStart` fires, so a probe verifying repo state can silently mutate the tree it was checking
- [hooks cannot inject tool calls](hook-cannot-inject-tool-calls.md) — no `injectToolCall`/`forceRead`/`requestTool`/`forceToolUse` field exists — only block, `updatedInput`, `updatedToolOutput`, `additionalContext`; a large `additionalContext` is spilled to a file with only ~2KB inlined, and injected text still leaves `Edit` needing a `Read`
- [hook output channels](hook-output-channels.md) — `systemMessage` vs `additionalContext` vs stderr (`additionalContext` is honoured at PreToolUse too), that `systemMessage` renders ANSI, what a hook ERROR does, and that only exit 2 blocks (PreToolUse only)
- [CC worktree memory freeze](cc-worktree-memory-freeze.md) — in-process `EnterWorktree` chdirs but never moves projectRoot, so `CLAUDE_PROJECT_DIR`/`PATH`/`autoMemoryDirectory` stay at the launch repo and auto-memory strands there; cwd≠`CLAUDE_PROJECT_DIR` is the D15 drift signal
- [git replay hooks](git-replay-hooks.md) — `rebase --continue` does NOT fire `pre-commit` (2.47.3), but cherry-pick/revert `--continue` and a hand commit/`--amend` at the stop DO; a non-zero exit aborts the REBASE, not a commit; detect via `--git-path rebase-merge|rebase-apply|CHERRY_PICK_HEAD|REVERT_HEAD`; `MERGE_HEAD` is not a replay
- [git stderr + parsing mechanics](git-stderr-and-parsing.md) — which git queries are silent on normal-absence; `(fetch first)`/`(non-fast-forward)` = divergence vs `(pre-receive hook declined)` = policy; `fetch -q` prints NOTHING on rejection while `push -q` still reports; `--git-common-dir` is relative in a main worktree → CDPATH trap; `-z --get-regexp`
- [Justfile shebang indentation](justfile-shebang-indent.md) — shebang recipe lines must share a common indent; column-0 body lines break parsing, don't blame the embedded language
- [claude-plugin-dev toolkit](claude-plugin-dev.md) — shared release infra for ddaa's plugins; VERSION file SOT, self-release recipe, marketplace bump
- [JSONL sidechain segregation](jsonl-sidechain-segregation.md) — main session JSONLs never carry `"isSidechain":true`, so a reader of `transcript_path` needs no sidechain filter; sub-agents live in `<session-id>/subagents/agent-<agent_id>.jsonl`, `archived/` holds retired whole sessions
