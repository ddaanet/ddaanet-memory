# ddaanet tier index

Portable facts that hold across every ddaanet project — tool and Claude Code
behaviour, design and review lessons, commit conventions. Project-specific
facts stay in the project's own memory store.

- [sandbox effects](sandbox-effects.md) — `There is no active session!` from `zellij run` under the Bash tool, or `/revdiff:revdiff` / `launch-revdiff.sh` exiting 1 with no output inside zellij (`ZELLIJ` set): the sandbox hides zellij's socket
- [examine evidence for drift and lineage](examine-evidence-drift.md) — two co-maintained artifacts diverge, or one is cited as evidence about the other (a sibling, a prior version): establish the relationship from git history, never assumption
- [harden human gates, not controlled channels](harden-human-gates.md) — where word-boundary/escape recognition belongs: human free-text vs a channel whose producer you control
- [CC worktree memory freeze](cc-worktree-memory-freeze.md) — in-process `EnterWorktree` chdirs but never moves projectRoot, so `CLAUDE_PROJECT_DIR`/`PATH`/`autoMemoryDirectory` stay at the launch repo and auto-memory strands there; cwd≠`CLAUDE_PROJECT_DIR` is the D15 drift signal
- [CC worktree Bash guard](cc-worktree-bash-guard.md) — a worktree session adds a Bash gate refusing `eval` and "too complex to verify that it stays inside the worktree" commands, blaming git isolation on commands touching no git; `pushd` is the drift stand-in
- [CC subagent worktree base](cc-subagent-worktree-base.md) — a subagent `isolation: worktree` shows old files at the `main` commit because unpushed `dev` was not its base: `worktreeBaseRef` / `worktree.baseRef` = `head` branches from local HEAD; the auto-mode classifier denies `git merge --ff-only` and `git reset --hard` run by an agent inside a worktree; `.claude/worktrees/` shows untracked in the parent's `git status`
- [markdown reflow gate](markdown-reflow-gate.md) — wiring a markdown hard-wrap gate (rumdl 0.2.74): the gate is `rumdl fmt --check -q --no-cache`, never `rumdl check` — permanently red on a line it cannot wrap; `include = ["*.md"]` is not root-anchored, the `*` crosses `/` and pulls in `plans/`, `memory/`, `.claude/` — root-level files are `/*.md`; without `--no-cache` a `.rumdl_cache/` dir appears in the tree; `reflow = true` alone only breaks over-limit lines and never converges widths (a ~70-col doc comes out *longer*) — `reflow-mode = "normalize"` re-fills paragraphs and is what a line-count cap is measured against, formatter check ahead of the line guard (the ddaanet size cap counts bytes and needs no reflow); reflow adds `>` to wrapped blockquote continuations, realigns table separators, and breaks any checker that greps a `- ` bullet line for content
- [rumdl unwrappable span](rumdl-unwrappable-span.md) — `[MD013] Line length N exceeds 80` left by `rumdl fmt` on a long code span or `*`/`**` emphasis run: fmt re-joins a hand split; move the span into a fenced block — punctuation after the closing backtick is lost and a hand-wrapped span's newline becomes a real break
- [uv: sync only, direnv venv](uv-direnv-venv.md) — no `uv run` under Claude; `uv sync` only + direnv exports VIRTUAL_ENV & PATH prefix; recipes call bare `pytest`; the venv python3 shadows the system one, so every module scripts on PATH probe for goes in the dev group (`need … PyYAML`); a symlink to the venv's python3 resolves to the base interpreter and loses site-packages — borrow it with an `exec` wrapper and probe through the shim
- [detect liveness, not presence](detect-liveness-not-presence.md) — probing a foreign tool's state file: why `[ -f known/path ]` false-positives
- [placeholder memory remote is by design](gitlore-placeholder-remote-is-by-design.md) — a store with no `origin` on a `./.git/gitlore-placeholder` url is a finished install, not a stalled migration: the parent has no remote, so read the PARENT's `git remote -v` before filing it as pending work
- [a guard reveals a singleton](guard-reveals-singleton.md) — a finding ending in "add a mutual check" means a singleton is modelled as N *named* instances
- [Transcripts are ground truth](transcripts-are-ground-truth.md) — a corrupted subagent artifact: transcripts hold the verbatim tool inputs to diff against
- [Migration backfill needs a runnable window](migration-backfill-needs-window.md) — pairing a NOT NULL schema change with a backfill-by-event script: verify the backfill can run against real legacy data before the reducer enforces the field, not after merging
- [Guard safety visible in the pattern](guard-safety-visible-in-the-pattern.md) — narrowing a guard's accepted class: what writers need vs what you can prove inert
- [Instruction names absent data](instruction-names-absent-data.md) — an agent body naming an input the harness never emits ("check the packet's topic list") reads as the agent ignoring it, so rubric/wording/model-tier fixes all look right and all miss; grep the producing code for the field, and render the missing input inside the consumer's budgeted body with an explicit empty marker
- [Codex plugin bugs and workarounds](codex-plugin-bugs.md) — `/codex:review` refused or "no actionable defects"/"no regressions" after a skim: use adversarial-review --base with a focus file as its own argv (template leaves `$(cat …)` unquoted); companion and `/codex:cancel` need sandbox off (`mkdir …/jobs` ENOENT, EROFS, `error building bubblewrap command`); `--model` needs a full slug from `~/.codex/models_cache.json` (short `astra`/`sol` fail "not supported when using Codex with a ChatGPT account"), no `--effort`; "codex-code-mode-host is missing"
- [Auditing a contract across its surfaces](audit-a-contract-across-its-surfaces.md) — reviewing against a finding list, or a contract whose rule, enforcer and consumer live in separate files: read the three surfaces against each other — per-site verification passes while every seam goes unchecked
- [memory frontmatter stamping](cc-memory-frontmatter-stamping.md) — who writes `node_type`/`originSessionId`/`modified`: one function, `stampNewMemoryContent`, on the Edit/Write/memory-write handlers only — never a Bash write; `originSessionId` is written only when absent, so it names the first tool write, not the creator; skips log `not stamping provenance`/`not dating` at warn
- [reflow joins field lines](reflow-joins-field-lines.md) — a bullet with one field per continuation line (`Requirements:`, `Model:`, `Change:`) is one paragraph to markdown, so `just format-docs`/rumdl MD013 re-fills it into prose; write a field list as a nested list
- [security review flags red-check mutations](security-review-flags-red-check-mutations.md) — `Background security review found: guard-bypass`/`fail-open` on an uncommitted guard line is usually a delegate's red-check mutation: mark mutations `MUTATION`, gate commits on the grep; a finding on committed or unmarked code is real until probed
- [bash 3.2 on Linux](bash32-macos-traps.md) — building Mac's bash 3.2.57 on Debian and running bats under it; the 3.2/macOS traps are in shell-gotchas' shell-versions and portability references
- [release review slicing](release-review-slicing.md) — fanning out `edify:release`'s Fable `/code-review high main...dev` over file slices when the delta is too large for one agent: each slice writes the forked review's out-of-slice findings to a file instead of dropping them (two of five highs came from them once); a slice stays near 20 files or under ~150k agent tokens
- [atomic commits](feedback-atomic-commits.md) — atomic commits per topic, never commit plans/ without being asked, a same-topic follow-up amends but a review-finding fix is its own commit, TASK.md, TODO.md, a pointer bump or settings noise amend into the previous commit when they belong to it by topic and it is unpushed, else ride the next commit they belong to
- [claude-plugin-dev toolkit](claude-plugin-dev.md) — installing or updating the claude-plugin-dev toolkit vendored into `plugin-dev/` at a `dist-vX.Y.Z` tag: `plugin-dev/README.md` is the manual; ``Recipe `release` has unknown dependency `prerelease` `` from `just` means the justfile lacks the `prerelease` recipe it documents
- [gitlore stale hook shim](gitlore-stale-hook-shim.md) — `git push` prints `gitlore skipped: hooks dir is stale` and exits 0 with no memory published, or fails with `.git/gitlore-pre-push: exec: …/scripts/git-hooks/pre-push: not found`: run `(cd /abs/path/to/repo && claude -p ping)` unsandboxed, then push again
